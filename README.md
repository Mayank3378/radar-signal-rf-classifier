# 📡 Radar Signal Classifier — Random Forest

A live ML project applying **Random Forest** to classify radar returns from the ionosphere
as **good** (structure detected) or **bad** (signal passed through) — built as a practical
implementation task during a DRDO AI Engineer internship.

**🔗 Live app:** _add your Streamlit link here after deploying_

## Dataset
**Johns Hopkins University Ionosphere Database** (UCI ML Repository)
- 351 radar returns, collected by a phased-array system (16 antennas, ~6.4 kW) in Goose Bay, Labrador
- Each return probed with 17 radar pulses → each pulse gives a complex autocorrelation value
  (real + imaginary) → **34 continuous features per sample**
- Binary label: `good` (structure detected in ionosphere) / `bad` (signal passed through)

## Why Random Forest
- Handles 34 correlated continuous features with no manual feature engineering
- Ranks feature importance — shows which pulses carry the most useful signal
- Bagging + random feature subsets reduce overfitting vs a single decision tree
- **Verified on this dataset:** Random Forest (93.2%) beat a single Decision Tree (87.5%)
  on the identical train/test split

## Results

| Metric | Score |
|---|---|
| Test accuracy | **93.2%** |
| 5-fold CV accuracy | 93.2% (± 4.2%) |
| ROC-AUC | ~0.97 |
| Single Decision Tree (baseline) | 87.5% |
